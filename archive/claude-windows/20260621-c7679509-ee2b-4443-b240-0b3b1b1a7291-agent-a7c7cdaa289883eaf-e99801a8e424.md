114	    def _wsl_free_gb(self, wsl_path: str) -> Optional[float]:
115	        """Best-effort free space (GB) on the WSL filesystem holding ``wsl_path``.

117	        Returns None if it can't be determined (never raises). Used as a pre-run

119	        """

## PyTorch-Specific Index Configuration

You can configure PyTorch indexes in `pyproject.toml` using `[[tool.uv.index]]` with the `explicit = true` setting:

```toml
[[tool.uv.index]]
name = "pytorch-cpu"
url = "https://download.pytorch.org/whl/cpu"
explicit = true
```

The documentation states: `"We recommend the use of explicit = true to ensure that the index is _only_` `used for torch, torchvision, and other PyTorch-related packages"`

## Routing via tool.uv.sources

You can route `torch` and `torchvision` to specific backends using `[tool.uv.sources]`:

```toml
[tool.uv.sources]
torch = [
  { index = "pytorch-cpu" },
]
torchvision = [
  { index = "pytorch-cpu" },
]
```

## CPU vs CUDA Backend Selection

The guide demonstrates selecting between different backends (CPU-only, CUDA 11.8, 12.6, 12.8, 13.0, ROCm, Intel GPUs) by configuring separate indexes pointing to `download.pytorch.org/whl/{backend}` URLs and using environment markers:

torch = [
