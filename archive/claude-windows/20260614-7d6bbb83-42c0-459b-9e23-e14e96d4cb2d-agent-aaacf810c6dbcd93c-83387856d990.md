## Key Evaluation Metrics

The main evaluation metrics for temporal action segmentation include frame-wise accuracy (Acc), segmental edit score, and segmental F1 score at the IoU threshold k%, denoted as F1@k (k = {10, 25, 50}).

### Frame-wise Accuracy
Frame-wise accuracy is one of the most common evaluation metrics for action segmentation, but it does not account for temporal dependencies and long action classes have higher impact than shorter action classes, making it unable to reflect over-segmentation errors.

### Segmental Edit Score
The segmental edit score penalizes over-segmentation by measuring the ordering of predicted action segments independent of slight temporal shifts. This metric measures the difference between ground truth segments and predicted segments using the Levenshtein Distance between hypotheses and ground truths.

### F1@k (Segmental F1 Score)
Segmental F1 score (F1@k) has become popular recently and penalizes over-segmentation errors while ignoring minor temporal shifts between predictions and ground truth. F1@k is determined by the total number of actions but does not depend on the duration of each action instance, similar to mean average precision (mAP) with intersection-over-union (IoU) overlap criteria.
