494	               iou: float = DEFAULT_IOU) -> Tuple[Dict[str, Any], Dict[str, List[str]]]:
495	    """Score every tracked config over the golden corpus. Returns (snapshot, skipped-per-config).
496	
497	    ``snapshot`` is the serialisable structure stored as / compared to the baseline. ``skipped``
