# CausalTAD: Causal Attention and Temporal Causality

**Paper Title:** "Harnessing Temporal Causality for Advanced Temporal Action Detection"

## What "Causal" Refers To

In CausalTAD, "Causal" refers to **causal attention masking** and **temporal causality** in action boundaries—not causal inference or structural causal models. The approach restricts models to access only past or future context, mimicking real-world event progression.

## Causal Attention Mask Definition

The paper defines the causal mask mathematically:

> "M_ij = {0 if i≤j, -∞ otherwise}"

This ensures: "each position in the sequence can only attend to its past and present positions, effectively modeling temporal causality."

## Motivation: Past/Future Information Treated Equally

The core insight is that existing methods overlook causality:

> "these modules typically treat past and future information equally, overlooking the crucial fact that changes in action boundaries are essentially causal events"

The paper explains the practical motivation:

> "In real-world scenarios, action boundaries are usually influenced by causal events. For instance, the end of a running action typically depends on past occurrences"

## Implementation

The hybrid causal block combines:
- **Causal Mamba block** (forward and backward scanning)
- **Causal Attention block** (bidirectional MHSA with causal masking)

Both restrict temporal context to past-only or future-only independently.
