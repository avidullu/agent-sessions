# NoCo: Noise Correction for Weakly-Supervised Temporal Action Localization

## 1. Publication Venue and Date
The paper appears on arXiv as arXiv:2501.11124v2, dated January 2025.

## 2. Core Problem Addressed
NoCo identifies three types of noise in pseudo-labels generated by weakly-supervised models:

> "Issues with noisy labels include:(1) inaccurate boundary localization; (2) undetected short action clips; (3) multiple adjacent segments incorrectly detected as one segment."

The authors argue that "the noise in pseudo-labels would interfere with the learning of fully-supervised detection head, leading to significant performance leakage."

## 3. Named Components/Methods
NoCo consists of:

- **Context-Aware Label Augmentation (CALA)**: Refines instance boundaries through weighted averaging of neighboring instances
- **Ambiguous Instance Correction (AIC)**: Addresses "many-to-one" problems by mining high IoU instances
- **Missing Instance Compensation (MIC)**: Solves short-action omissions by identifying compensation instances with low IoU ratios
- **High-quality Pseudo-label Mining (HPM) Loss**: Assigns adaptive weights to training instances

The framework operates in two stages: pseudo-label generation with CALA, then online correction via teacher-student training.

## 4. Quantitative Results

**THUMOS14:**
- Achieves 50.9% average mAP (6.1% improvement over CO2-Net baseline)
- Surpasses previous state-of-the-art PivoTAL
- 3× faster inference speed

**ActivityNet v1.2:**
- Achieves 30.7% mAP (4.2% improvement over ASM-Loc)
- Outperforms prior state-of-the-art methods

Ablation studies show cumulative gains: CALA (+1.3%), Teacher-Student framework (+2.0%), AIC (+2.2%), MIC (+1.8%), combined AIC/MIC (+4.1%), HPM (+0.2%).

## 5. How It Handles Label Noise

The framework uses two-stage correction:

Stage 1: CALA applies "weighted aggregation of associated action instances" to correct boundaries before downstream training.

Stage 2: An "online-revised teacher-student framework" leverages "weighted aggregation of multiple historical student models" to generate stable correction signals, progressively updating pseudo-labels during training.

## 6. Pseudo-Label Quality and Training Strategy

> "our approach introduces several key innovations. Firstly, to generate robust and stable pseudo-label compensation information, our teacher model employs weighted aggregation of multiple historical student models."

Importantly: "the inference process of NoCo does not depend on the WTAL base model. In this paper, we build a student model based on the efficient TAL model TriDet, and during the inference phase, only the student model needs to be run."
