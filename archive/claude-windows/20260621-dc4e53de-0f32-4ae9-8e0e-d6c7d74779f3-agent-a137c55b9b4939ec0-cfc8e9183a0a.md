Three interchangeable impls — `WasbRunner` (WSL), `NativeWasbRunner` (Linux GPU), `StubDetectorRunner` (CPU mock) — emit the **identical CSV schema**. 67	2. **WINDOW (CPU pure fn):** `trajectory_to_action_windows(points, fps, frame_width, …) → windows` (`tracknet_runner.py:281`). 88	### 4.4 Compute placement — and *why stitch runs on Cloud Run* `[design]`
89	DETECT on GPU everywhere; WINDOW CPU-pure everywhere; STITCH is real CPU work. (Stitch stays synchronous in the GPU job for the common one-reel case; a queued CPU-only stitch fallback only if compiles get bursty — the job table + `claim_due_job` already supports both.)

7	    """Validate an output filename is a BARE name (no dir part, no traversal, not absolute).
8

10	    and `..` segments escape it — so an unchecked `output_filename` is an arbitrary-write
11	    primitive. Returns the name unchanged when safe; raises ValueError otherwise.

20	        raise ValueError(f"output_filename must be a bare filename, got: {name!r}")
21	    return name
