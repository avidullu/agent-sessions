## Main Issues and Pitfalls

**Large Executable Sizes:**
PyInstaller executables using PyTorch, OpenCV, and PyQt5 libraries can reach approximately 250MB or more.

**Hidden Imports and Metadata Issues:**
PyTorch requires metadata to be collected during bundling, which can be done by adding --copy-metadata torch to your PyInstaller command. Additionally, specific hidden imports like torch._C._jit and torch._C._nvrtc may need to be explicitly included.

**File Duplication Problems:**
When building onefile applications with torch, warnings about file duplication can occur, such as "WARNING: file already exists but should not" for files like torch/_C.cp39-win_amd64.pyd.

## Size Optimization Strategies

To reduce executable size, several approaches are recommended:

1. Using the --exclude-module option to exclude unnecessary modules, such as torch.cuda if CUDA is not needed

2. Excluding modules like torchvision, matplotlib, pandas, and scipy when not needed, and using opencv-python-headless instead of the full OpenCV package

3. Using tools like UPX for compression or exporting models to more efficient formats like ONNX

## The Issue

PyInstaller's --onefile mode creates a single executable that extracts everything to a temporary folder at runtime. This extraction behavior is one of the things that triggers AV heuristics. This extraction-and-execution pattern is exactly what a lot of actual malware does. Malicious software often uses "packers" to compress and hide their payloads, extracting them at runtime to avoid detection.
