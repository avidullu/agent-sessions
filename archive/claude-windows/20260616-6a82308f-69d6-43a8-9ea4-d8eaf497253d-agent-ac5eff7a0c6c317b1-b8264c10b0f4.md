# ASRF: Action Segment Refinement Framework

**Purpose:**
ASRF is a framework designed to improve temporal action segmentation by addressing over-segmentation errors—instances where action boundaries are incorrectly predicted, resulting in fragmented segments.

**Architecture:**
The framework consists of two key components working with shared long-term features:

1. **Action Segmentation Branch (ASB)**: Classifies individual video frames into action categories
2. **Boundary Regression Branch (BRB)**: "regresses the action boundary probabilities" to identify where one action transitions to another

**How It Addresses Over-segmentation:**
The BRB predictions refine ASB outputs by detecting precise action boundaries. Rather than relying solely on frame-level classification, the framework uses boundary detection to smooth transitions and correct fragmented predictions. As stated in the abstract, "The action boundaries predicted by the BRB refine the output from the ASB, which results in a significant performance improvement."

**Results:**
The approach demonstrates substantial improvements, achieving gains of up to 13.7% in segmental edit distance and 16.1% in segmental F1 score across three benchmark datasets, indicating it effectively reduces over-segmentation artifacts.
