# pikepdf Password and Encryption Documentation

## Password Parameter (Pdf.open())

The `password` parameter accepts either a string or bytes:

- **String input**: "If the type of this parameter is `str` it will be encoded as UTF-8."
- **Bytes input**: "If the type is `bytes` it will be saved verbatim."
- **Processing**: "Passwords are always padded or truncated to 32 bytes internally."
- **Compatibility**: "Use ASCII passwords for maximum compatibility."

## Encryption Parameter (Pdf.save())

The `encryption` parameter accepts three types of values:

1. **False or omitted**: "existing encryption will be removed"
2. **True**: "encryption settings are copied from the originating PDF"
3. **Encryption object**: "an `Encryption` object may be provided that sets the parameters"

## Supported Encryption Algorithms

The `Encryption` class supports the following configurations:

**Security Handler (R parameter)**: Versions 2, 3, 4, or 6, with version 6 as default ("the highest version of is selected")

**Cipher options**:
- **AES**: Available when R ≥ 4; enabled by default
- **RC4**: Used when AES is not selected

**Specific algorithm support**:
- AES-256 with R6 (default configuration)
- AES with earlier R versions when `aes=True`
- RC4 when `aes=False`

**Additional settings**: The `Encryption` object allows configuring user/owner passwords, permissions, and metadata encryption.
