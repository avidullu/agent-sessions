## Cascade Object Detection Overview

## The Viola-Jones Rejection Cascade

The Viola-Jones algorithm is a machine-learning technique for object detection proposed in 2001 by Paul Viola and Michael Jones in their paper "Rapid object detection using a boosted cascade of simple features" and was primarily conceived for face detection.

The basic idea uses multiple classification stages with increasing complexity, where each stage detects almost all objects of interest while rejecting a certain fraction of non-objects, with the majority of non-objects rejected by early stages with little processing time spent.

## Hard Cascade Mechanism

The Viola Jones Algorithm for face detection used hard cascades by Adaboost, where a strong region classifier is built with a cascade of many weak classifiers focusing attention on different features, and if any weak classifier rejects the window, there will be no more processing.

## Key Features

The Viola-Jones detector combined multiple techniques like Haar-like features, integral image, Adaboost and cascading classifier, first searching for Haar-like features by sliding a window on the input image and using integral image to calculate, then using trained Adaboost to find the classifier of each haar feature and cascading them.
