71	## 2. Marginal contribution — the core measurement
72	
73	For a full signal set `S` and a signal `s`, the **marginal contribution** of `s` is:
74	
75	```
76	Δ(s) = score(full set S) − score(S \ {s})         # leave-one-out drop
77	```
78	
79	measured as **ΔF1** (primary), with **F1@k + segment-count-ratio** alongside (C4 — over-seg that
80	tIoU hides). Operationally this is exactly:
81	
82	```python
83	full     = Variant(name="full",       feature_names=ALL_COLUMNS, min_crossings=2, ...)
84	without_s = Variant(name=f"−{s.name}", feature_names=[c for c in ALL_COLUMNS if c not in s.columns],
85	                    min_crossings=(0 if s.gate_knob=="min_crossings" else 2))
86	res = compare(golden_videos, variant_a=without_s, variant_b=full, honest_stats=True)
87	#         A = ablated (smaller), B = full  →  result["honest"]["paired_delta_f1"] is Δ(s),
88	#         a per-video-paired ΔF1 with bootstrap CI + exact sign test, LOVO-honest if learned.
89	```
90	
91	Reading `compare`'s `honest` block gives, per signal, for free:
92	- `paired_delta_f1.mean_delta` — the marginal ΔF1 (B−A = full−ablated);
93	- `paired_delta_f1.ci_low/ci_high` + `ci_excludes_zero` — is the drop real at n=6?
94	- `paired_delta_f1.sign_test` — did removing `s` hurt on a MAJORITY of videos?
95	- the C4 segmentation block — did removing `s` fragment/merge rallies even if F1 barely moved?
96	
97	A signal is **earning its keep** when removing it produces a drop whose **CI excludes 0 AND the
98	sign test agrees** (≥ the majority of videos got worse) — the same bar `per_user_gate` /
99	promotion use, applied in reverse. A signal is **candidate dead weight** when removal is a wash
100	(`mean_delta ≈ 0`, CI spans 0, sign test n.s.) **across multiple iterations** (§4 — one wash is
101	noise at n=6, a *trend* is signal).
102	
103	> ⚠ **LOSO is necessary but not sufficient.** Leave-one-out attributes the *unique* contribution
104	> of `s` given everything else present. It MISSES redundancy and synergy: two signals each useless
105	> alone but jointly useful both show ≈0 LOSO drop (each is covered by the other → "drop one, the
106	> other compensates"); and a signal can look free under LOSO yet be the linchpin of a pair. §5 adds
107	> leave-PAIR-out + backward elimination to recover this. **Report LOSO as the screening pass, never
108	> as the final verdict to delete a signal.**

181	  "full_set_hash": "253f4709b4c4",       // spec_hash of the full Variant at this iteration

194	**Why it's a time series, not a snapshot.** As the full set evolves (a new cue lands, a label is
195	fixed, the corpus grows), each signal's marginal contribution is RE-MEASURED *against the new full
196	set*. So `gate_a`'s row in run-1 and run-7 are comparable points on a curve. A reader (or a tiny
197	report tool) can ask:
198	
199	- **"Is `person` still dead weight?"** → plot `delta_f1` for `person` across runs. Persistently
200	  ≈0 with CI spanning 0 → flag `STALE` (candidate for removal / archival).
201	- **"Did `gate_a` decay when audio landed?"** → a once-strong signal whose marginal contribution
202	  *shrinks* as a newer signal subsumes it = quantified **redundancy onset** (the newer signal now
203	  carries what the old one used to). This is the dead-weight question answered with a number.
204	- **"Did corpus growth resolve audio?"** → `audio`'s CI should TIGHTEN as n grows; a contribution
205	  that was "uncertain (CI spans 0) at n=6" becoming "earns keep (CI clears 0) at n=20" is the
206	  honest promotion trigger — and the inverse (still spanning 0 at large n) is honest demotion.
207	
208	**Staleness flag (quantified dead-weight rule).** A signal is flagged `STALE_CANDIDATE` when, over
209	the **last K runs** (K≥3, configurable) at a comparable n: every run's `ci_excludes_zero == false`

224	## 5. Redundancy & interaction — when LOSO lies
225	
226	Three named failure modes of naive leave-one-out, and the handling for each (cost-ordered cheap→dear):
227	
228	| Failure mode | What LOSO shows | What's true | Handler |
229	|---|---|---|---|
230	| **Redundancy** (two signals carry the same info) | each LOSO Δ ≈ 0 (the other compensates) | together they're load-bearing; dropping BOTH tanks F1 | **leave-PAIR-out** + **backward elimination** |
231	| **Synergy / XOR** (useless alone, useful together, e.g. `shuttle_in_air AND person_two_sided`) | each LOSO Δ ≈ 0 (or even +) | the PAIR is the contribution; a linear arbiter can't even see it | **leave-pair-out** + an **interaction column** (C7) |
232	| **Suppressor** (a signal helps only by correcting another) | LOSO Δ small | removing it *with* its partner changes the story | **backward elimination** path-dependence note |
233	
234	**(a) Leave-pair-out (LPO).** For the suspect set (signals whose LOSO Δ spans 0), also run
235	`compare(full − {s_i, s_j}, full)` for each pair. If a pair's joint drop's CI clears 0 while *both*
236	singletons' did not → **redundant-but-jointly-useful**: keep both, do NOT cut either on LOSO
237	evidence. Cost: `O(k²)` comparisons vs `O(k)` for LOSO — bounded (k≈4 groups → 6 pairs), and only
238	run on the LOSO-ambiguous subset, so cheap in practice. Gate it behind a flag (`--pairs`); default
239	LOSO-only.
240	
241	**(b) Backward elimination (greedy, honest).** The decision procedure that *uses* the marginal
242	numbers: starting from the full set, repeatedly drop the signal whose removal is the **least
243	harmful** (most-positive / least-negative ΔF1 with CI NOT clearing 0), re-measure the new full set,
244	repeat until every remaining signal's removal measurably hurts (CI clears 0 + sign agrees). The
245	surviving set is the **honest minimal sufficient signal set**. This is the principled answer to "trim
246	dead weight" — and it is path-dependent by construction (it re-measures after each drop), so it
247	catches redundancy that one-shot LOSO can't. Cost: `O(k²)` worst case; report the elimination *path*
248	(order + Δ at each step) in the ledger so the trim is auditable, not a black box.
249	
250	**(c) Shapley-style attribution (optional, owner-gated, higher cost).** The theoretically-fair
251	"average marginal contribution over all subset orderings" — the only attribution that is order- and
252	redundancy-fair. Exact Shapley is `O(2^k)` full-set evaluations; at **k≈4–6 signal GROUPS this is
253	16–64 evals — entirely affordable offline** (re-scoring is cheap; detection is already persisted).
254	So: **exact Shapley over GROUPS** is in scope as an opt-in (`--shapley`), Monte-Carlo Shapley only if
255	k ever grows past ~10 columns. Report it as a *complement* to backward elimination (Shapley says "fair
256	credit"; backward elimination says "what's safely droppable"), with the same CI honesty — each subset
257	eval is itself a LOVO mean, so a Shapley value carries propagated small-N uncertainty and must not be
258	over-claimed at n=6.
259	
260	**Cost trade-off summary (what to run when):**
261	- **Always:** LOSO + LOGO (Phase 0) — `O(k)`, the screening table.
262	- **On LOSO-ambiguous signals:** leave-pair-out (`O(k²)` on a subset) — catches redundancy/synergy.
263	- **For a trim decision:** backward elimination (`O(k²)`) — the minimal-set procedure + audit path.
264	- **For paper-grade fair credit:** exact Shapley over groups (`O(2^k)`, k≤6) — opt-in.
265	- **Interaction recovery for the scorer itself:** add hand-crossed product columns (C7) so the linear
266	  arbiter can *represent* a synergy LPO surfaced — then that interaction is itself an ablatable signal.

271	
272	The whole point is honest verdicts at n=6, where a single mean lies. Reuse `eval_stats` and

274	
275	1. **Never a bare mean.** Every Δ(s) ships with a bootstrap 95% CI + the exact paired sign test
276	   (`paired_delta_ci`). A row with no CI is a bug.
277	2. **A signal "earns its keep" only when** removing it drops F1 with **CI excluding 0 AND sign test
278	   agreeing** (majority of videos worse, `p ≤ p_threshold`) — the `per_user_gate` bar, in reverse.
279	3. **"Dead weight" needs a TREND, not one run.** A single wash at n=6 is *insufficient evidence*, not

281	   honest version of "remove it." Until then the verdict is literally `uncertain`, never `irrelevant`.

283	   guard whose value is in failure modes the golden corpus may lack (Gate-A vs held-shuttle FPs) is

286	5. **Group by match for the eval folds** (video-LOVO via `compare`'s honest path) — never a held-out
287	   window from the same video; the small corpus's LOOCV anti-correlation bias (C1) is why CIs, not
288	   means, gate.
289	6. **Multiplicity caveat.** Ablating k signals = k simultaneous tests; at k≈4 we report raw p-values
290	   but **note the family-wise risk** in the ledger header (a Holm/BH correction is a one-liner to add
291	   when k grows — flagged, not yet applied, to avoid over-engineering at k=4).

293	   `uncertain` / `candidate_dead_weight(trend)` / `structural_protected` — it MUST NOT print

32	def bootstrap_ci(values: Sequence[float], confidence: float = 0.95,
33	                 n_boot: int = 2000, seed: int = 0) -> Tuple[float, float]:
34	    """Percentile bootstrap CI for the mean of ``values``. Deterministic given ``seed``.
35	
36	    ``n<=1`` returns a degenerate ``(v, v)`` / ``(0, 0)`` interval — there is no spread to
37	    resample. With n=6 (our corpus) this is the honest "how wide could the mean be?" band.
38	    """
39	    vals = [float(v) for v in values]
40	    n = len(vals)
41	    if n == 0:
42	        return (0.0, 0.0)
43	    if n == 1:
44	        return (vals[0], vals[0])
45	    rng = random.Random(seed)
46	    means: List[float] = []
47	    for _ in range(max(1, n_boot)):
48	        means.append(sum(vals[rng.randrange(n)] for _ in range(n)) / n)
49	    means.sort()
50	    alpha = (1.0 - confidence) / 2.0
51	    last = len(means) - 1
52	    lo = means[max(0, int(math.floor(alpha * last)))]
53	    hi = means[min(last, int(math.ceil((1.0 - alpha) * last)))]
54	    return (lo, hi)

69	def paired_sign_test(deltas: Sequence[float], eps: float = 0.0) -> Dict[str, float]:
70	    """Two-sided exact sign test over per-fold deltas (B − A).
71	
72	    ``wins`` = folds where B beat A by more than ``eps``; ``losses`` the reverse; ties
73	    excluded. ``p_value`` is the exact two-sided binomial tail under p=0.5 — the
74	    distribution-free "did B win on enough *videos*?" check.
75	    """
76	    wins = sum(1 for d in deltas if d > eps)
77	    losses = sum(1 for d in deltas if d < -eps)
78	    ties = len(deltas) - wins - losses
79	    n_eff = wins + losses
80	    if n_eff == 0:
81	        p = 1.0
82	    else:
83	        k = min(wins, losses)
84	        tail = sum(math.comb(n_eff, j) for j in range(k + 1)) * (0.5 ** n_eff)
85	        p = min(1.0, 2.0 * tail)
86	    return {"wins": float(wins), "losses": float(losses), "ties": float(ties),
87	            "n_effective": float(n_eff), "p_value": p}

53	    """Average precision at a single tIoU (all-points / VOC-2010 interpolation).
54	
55	    Predictions are ranked by descending confidence; each is a true positive iff it
56	    claims a still-unmatched ground-truth rally at IoU >= ``iou_threshold`` (highest
57	    available IoU wins, one GT per prediction). Returns AP in ``[0, 1]``. ``0.0`` when
58	    there are no ground-truth rallies or no predictions reach the threshold.
59	    """
60	    n_gt = len(gts)
61	    if n_gt == 0 or not scored_preds:
62	        return 0.0

64	    order = sorted(range(len(scored_preds)),
65	                   key=lambda i: (-scored_preds[i][1], i))   # conf desc, stable by index
66	    matched_gt = set()

68	    recalls: List[float] = []

83	        else:
84	            cum_fp += 1
85	        precisions.append(cum_tp / (cum_tp + cum_fp))
86	        recalls.append(cum_tp / n_gt)

88	    # Monotone precision envelope (take the max precision to the right), then integrate
89	    # over recall steps: AP = sum_k (recall_k - recall_{k-1}) * precision_env_k.
90	    for i in range(len(precisions) - 2, -1, -1):
91	        precisions[i] = max(precisions[i], precisions[i + 1])

(the design) and ``docs/ABLATION_LAYER.md`` (the shipped note).

``experiment.compare`` + ``eval_stats`` engine, exactly as ``compare`` was a driver over
``metrics``/``calibration``. For each signal ``s`` the marginal contribution is:

    Δ(s) = score(full set S) − score(S \\ {s})            # leave-one-out drop, ΔF1 primary

def _ablated_variant(full: Variant, columns: Sequence[str], gate_knob: Optional[str]) -> Variant:
    """Build the leave-one-out (smaller) variant from ``full``: drop ``columns`` from its
    ``feature_names`` and/or zero the named gate knob. Pure — derives a new Variant, never
    mutates ``full``."""

    overrides: Dict[str, Any] = {"feature_names": ablated_fn}

    elif gate_knob == "min_players":

def _seg_ratio(variant: Variant, videos: Sequence[VideoCandidates]) -> float:
    """Mean predicted-to-GT segment-count ratio across videos (C4 over-seg diagnostic).

    For a learned variant we can't score without a model, so this is only meaningful for the
    static-gate case the litmus uses; learned-variant rows still record it best-effort and fall
    back to 0.0 when a model is required (the CI/sign verdict does not depend on it)."""

    ratios: List[float] = []
    for vc in videos:
        try:
            preds = experiment.predict(variant, vc)
        except experiment.ExperimentError:
            return 0.0
        ratios.append(segm.segment_count_ratio(preds, vc.gts or []))

def _classify(structural: bool, ci_excludes_zero: bool, sign_wins: int, sign_losses: int,
              sign_p: float, p_threshold: float) -> Tuple[str, bool]:
    """The honest verdict (no over-claim). Returns ``(verdict, structural_protected)``.

    A structural guard is reported but never demoted on "no lift". Otherwise: removing the
    signal *earns its keep* when the ΔF1 CI clears 0 AND the sign test agrees (majority worse on
    removal, ``p <= p_threshold``); a positive-leaning but CI-spanning row is ``suggestive``; a
    wash this run is ``inert`` (a candidate, never "proven useless" at n=6)."""
    if structural:
        return STRUCTURAL_PROTECTED, True
    sign_agrees = (sign_p <= p_threshold) and (sign_wins > sign_losses)
    if ci_excludes_zero and sign_agrees:
        return EARNS_KEEP, False
    if sign_wins > sign_losses:           # leans toward "removal hurts" but evidence is thin
        return SUGGESTIVE, False
    return INERT, False

def _collapse_to_groups(signals: Sequence[Signal]) -> List[Signal]:
    """Collapse a LOSO inventory into one Signal per producer GROUP (LOGO): union the columns,
    OR the gate knob, OR the structural flag. First-seen group order is preserved."""
    order: List[str] = []
    by_group: Dict[str, List[Signal]] = {}
    for s in signals:
        if s.group not in by_group:
            order.append(s.group)
            by_group[s.group] = []
        by_group[s.group].append(s)
    out: List[Signal] = []
    for g in order:
        members = by_group[g]
        cols: Tuple[str, ...] = tuple(dict.fromkeys(c for m in members for c in m.columns))
        knob = next((m.gate_knob for m in members if m.gate_knob), None)
        structural = any(m.structural for m in members)
        out.append(Signal(name=g, group=g, columns=cols, gate_knob=knob, structural=structural))
    return out

    lines = [header, "", _fmt_row(cols), _fmt_row(["-" * w for w in widths])]
    for r in rows:
        ci = f"[{r.ci_low:+.3f}, {r.ci_high:+.3f}]"
        sign = f"{r.sign_wins}W/{r.sign_losses}L p={r.sign_p_value:.3f}"
        verdict = VERDICT_LABEL.get(r.verdict, r.verdict)
        lines.append(_fmt_row([r.signal, f"{r.delta_f1:+.3f}", ci, sign,
                               "yes" if r.ci_excludes_zero else "no", verdict]))
    return "\n".join(lines)

    rows = report.sorted_rows()
    story: List[Any] = [
        Paragraph("Signal Ablation &amp; Feature-Enablement Report", title),

# Ablation layer (Phase 0) — per-signal marginal contribution

A *systematic, repeatable* version of the one-off ablation (`scratch/gate_ab_ablation.py`):
`backend/eval/ablation.py` runs it and it EXCLUDES one signal, measures whether quality dropped,
and reports each signal's **marginal ΔF1** (full set vs full-minus-that-signal) with a bootstrap
95% CI + paired sign test + the C4 over-segmentation ratio. The full design (the ledger time
series, interaction handling, per-user ablation, the phased plan) lives in
[`../scratch/ABLATION_FRAMEWORK_PLAN.md`](../scratch/ABLATION_FRAMEWORK_PLAN.md); this note covers
only the shipped Phase-0 runner.

## What it is (and is not)

**A pure driver.** No new scoring/stats math — every number defers to the shipped
`experiment.compare` + `eval_stats` engine, exactly as `compare` was a driver over
`metrics`/`calibration`. For a signal `s`:

```
Δ(s) = score(full set S) − score(S \ {s})        # leave-one-out drop, ΔF1 primary
```

is `experiment.compare(videos, variant_a=without_s, variant_b=full)` — A is the ablated (smaller)
variant, B is full, so the reported **B−A** ΔF1 IS Δ(s): a per-video-paired ΔF1 with bootstrap CI
+ exact sign test, LOVO-honest for learned variants.

A signal is either a **feature column** (person/audio/shuttle columns the learned scorer weights,
ablated by dropping the column) or a **gate knob** (Gate-A's `min_crossings` threshold, ablated by
zeroing the knob). The runner handles both uniformly.

## Two granularities

- **LOSO** (`--granularity signal`) — leave one column-set out at a time (fine-grained).
- **LOGO** (`--granularity group`) — leave a whole producer's columns out at once (the owner's
  "is this old SIGNAL still relevant?" question at cue granularity). Default.

## The honest small-N contract

Inherited from `eval_stats` / `per_user_gate` (no new statistics):

- **Never a bare mean** — every row ships a CI + the exact sign test.
- A signal **earns its keep** only when removal drops F1 with the ΔF1 **CI excluding 0 AND the
  sign test agreeing** (the `per_user_gate` bar, in reverse).
- **Structural guards are exempt from auto-demotion.** Gate-A (the held-shuttle false-positive
  killer) is marked `structural`; it is reported honestly but verdict is always
  `structural-protected`, never flagged dead weight on "no measured lift" — its value is in
  failure modes the golden corpus may not contain.
- The verdict vocabulary is closed and never over-claims: `clears-bar` / `suggestive` / `inert`
  / `structural-protected`. One wash at n=6 is `inert` (a candidate), never "irrelevant".
