### **SPA-to-Engine Authentication: No Custom Headers**

**File:** `backend/api/static/app.js`

All fetch calls (lines 88, 329, 373) send:
```javascript
headers: { "Content-Type": "application/json" }
// No Authorization, Cf-Access, or credentials fields
```

**How Auth Works in Production:**

1. User hits `https://app.khelsutra.guru` (Cloudflare Pages + Access)
2. CF Access shows email OTP or SSO gate → redirects to SPA if authenticated
3. CF Access injects a secure cookie (or the JWT in a header intercepted server-side)
4. SPA makes fetch to `https://api.khelsutra.guru/api/process`
5. Cloudflare Tunnel (running on the GPU box) forwards request to FastAPI `:8000`
6. FastAPI reads `Cf-Access-Jwt-Assertion` header (injected by CF proxy, unreplicable from the browser)
7. If edge-auth enabled, verifies JWT; sets `owner_id` on the job

**Bottom Line:** The SPA is **auth-agnostic**. It relies on CF Access being the auth layer, not the API itself. The API just parses the header CF injects.

### **CSRF & Hosted-Mode Interactions**

**File:** `backend/main.py:298-311` + `backend/utils/paths.py`

**CSRF:** Not needed here—`allow_credentials=False` + cross-origin means the browser won't auto-send cookies. The SPA must explicitly POST; an attacker's `<form>` will be blocked by CORS.

**Allowed Video Root (Hosted Mode):**
```python
allowed_root = getattr(getattr(global_config, "security", None), "allowed_video_root", None)
validate_input_path(req.video_path, allowed_root=allowed_root)
```

- **Unset (default):** No containment check—local mode can access any file the process user can read.
- **Set to `/uploads`:** FastAPI rejects `/etc/passwd` or `/home/user/private/video.mp4`; only allows paths under `/uploads`.

The check uses real-path normalization (`os.path.realpath`) + `os.path.commonpath` to detect `..` traversal.

**Gap in Hosted Mode:** If the SPA is public and `allowed_video_root` is not set, users can ask the engine to process any file on the box (info disclosure risk). This is intentional for single-user local mode; the owner must lock it down if going public.
