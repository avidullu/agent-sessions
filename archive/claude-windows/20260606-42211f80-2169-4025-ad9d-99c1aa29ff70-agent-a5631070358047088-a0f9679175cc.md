# VLC Lua Extension Lifecycle API

## Core Descriptor Function

**`descriptor()`** is mandatory for extension registration. Returns a table with these fields:

- `title` (required): Extension name
- `author`, `version`, `url`, `icon`: Metadata
- `shortdesc`, `description`: Documentation
- `capabilities`: List controlling which callbacks VLC invokes

### Capability Strings

- `"menu"`: Enables `menu()` and `trigger_menu(id)` calls
- `"trigger"`: Calls `trigger()` instead of `activate()`
- `"input-listener"`: Enables `input_changed()` callback
- `"meta-listener"`: Enables `meta_changed()` callback
- `"playing-listener"`: Enables `status_changed()` callback

## Lifecycle Callbacks

**`activate()`** – Invoked when user starts extension via View menu (unless `"trigger"` capability is declared)

**`trigger()`** – Called at startup if `"trigger"` capability replaces `activate()`

**`close()`** – Triggered when user closes the extension dialog window (not on View menu deactivation)

**`deactivate()`** – Called when extension is disabled via View menu

## Playback/Input Listeners

- **`input_changed()`** – Fires when "the input item has changed (e.g. When a new song is playing)"
- **`meta_changed()`** – Triggered upon metadata updates in player
- **`status_changed()`** – Activated on player status changes

All three require corresponding capability declarations to be invoked.

## Control Functions

**`vlc.deactivate()`** – Deactivates the extension programmatically

**`vlc.keep_alive()`** – Resets the watch timer to prevent timeout

# VLC Dialog Widget API Summary

## Creating a Dialog

```lua
local dlg = vlc.dialog(title)

```

"Constructor for the UI Dialog object" where `title` is a string. Returns a table representing the created dialog.

## Dialog Management Methods

- **`dialog:show()`** - "Show the dialog, create the window."
- **`dialog:hide()`** - "Hide dialog without closing it."
- **`dialog:delete()`** - "Close the dialog and delete it."
- **`dialog:set_title(title)`** - Change dialog title
- **`dialog:update()`** - "Updates the dialog without waiting for the current function to complete."
- **`dialog:del_widget(widget)`** - "Delete a widget from the dialog."

## Adding Widgets

All `add_*` methods accept optional grid parameters: `col`, `row`, `hspan` (horizontal span), `vspan` (vertical span), `width`, `height`.

**`dialog:add_button(text, func, ...)`**
- `text`: button display text (string)
- `func`: "Reference to the function that should be called when the button is clicked"
- Returns widget with `get_text()`, `set_text()` methods

**`dialog:add_label(text, ...)`**
- Returns widget with `get_text()`, `set_text()` methods

**`dialog:add_text_input(text, ...)`**
- Returns widget with `get_text()`, `set_text()` methods

**`dialog:add_check_box(text, checked, ...)`**
- `checked`: optional boolean (defaults to `false`)
- Returns widget with `get_text()`, `set_text()`, `get_checked()`, `set_checked()` methods

**`dialog:add_dropdown(...)`**
- Returns widget with `clear()`, `get_value()`, `add_value()` methods

**`dialog:add_list(...)`**
- Returns widget with `get_selection()`, `clear()`, `get_value()`, `add_value()` methods

## Widget Methods

**Dropdown/List - `widget:add_value(text, id)`**
- `text`: string display value
- `id`: optional integer identifier (defaults to 0)
- "Add an item to the widget"

**Dropdown/List - `widget:clear()`**
