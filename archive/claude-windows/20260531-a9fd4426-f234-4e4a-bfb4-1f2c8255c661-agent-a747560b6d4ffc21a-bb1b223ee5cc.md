# Vision LLMs for Table Recognition: Benchmark Summary

## Overview
This paper introduces a comprehensive benchmark for evaluating Vision Large Language Models (VLLMs) on table recognition tasks across hierarchical dimensions (cell, row, column, and table-level), using three datasets: SciTSR, PubTabNet, and WTW.

## Performance on Borderless/Semi-Ruled Tables

Interestingly, VLLMs show surprising resilience with missing borders. The analysis reveals that "modifications such as fading or removing these borders have minimal impact on the performance of VLLMs in TR tasks." The models don't heavily rely on structural borders for recognition, instead depending on cell content positioning.

However, **VLLMs underperform traditional OCR methods on the WTW dataset** (wild scenarios with complex table variations). While traditional methods achieved 93.86 TEDS-Struct, VLLMs with NGTR only reached 52.03 points, indicating persistent challenges with irregular table structures.

## VLLM Failure Modes

Key failure patterns identified:

1. **Row-Column Bias**: VLLMs prefer column-structured information over rows, struggling more with "row-related tasks" due to higher row similarity.

2. **Geometric Sensitivity**: Performance drops substantially under geometric deformations—tilting at 40 degrees causes severe accuracy loss.

3. **Complex Structures**: The models "tend to ignore cells lacking semantic content," causing failures on tables with many empty cells and dense packing.

4. **Context Confusion**: VLLMs can be "misled by its own reasoning...when encountering atypical table structures."

## Neighbor-Guided Toolchain Reasoner (NGTR)

NGTR is a training-free framework addressing image quality bottlenecks through:

- **Toolkit**: Five lightweight tools (upscaling, border enhancement, noise reduction, binarization, detection/cropping)
- **Neighbor Retrieval**: Uses similarity-based retrieval to find comparable training examples
- **Tool Selection**: Leverages neighbor experiences to generate multiple tool invocation plans
- **Reflection Module**: Iteratively validates each preprocessing step to prevent information loss

Results show significant improvements: +10.57 TEDS points on PubTabNet and +12.02 on WTW, demonstrating that guided preprocessing substantially enhances VLLM capabilities for challenging inputs.
