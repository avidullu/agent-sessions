## Overview
TriDet is a one-stage framework for temporal action detection that addresses imprecise boundary predictions by proposing a novel Trident-head to model the action boundary via an estimated relative probability distribution around the boundary.

## Trident-head Mechanism
The Trident-head consists of three components: a start head, an end head, and a center-offset head, which are designed to locate the start boundary, end boundary, and the temporal center of the action, respectively.

The key innovation involves probability distribution and expected value calculations. The predicted boundary response in neighboring bin set is summed element-wise with the center offset corresponding to the instant, which is further estimated as the relative boundary distribution, and finally, the offset is computed based on the expected value of the bin.

## Performance
TriDet hits an average mAP of 69.3% on THUMOS14, outperforming the previous best by 2.5%, but with only 74.6% of its latency.

## Additional Features
In the feature pyramid of TriDet, a Scalable-Granularity Perception (SGP) layer aggregates information across different temporal granularities, which is much more efficient than recent transformer-based feature pyramids.
