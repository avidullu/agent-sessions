42	**Three findings that drive the design:**
43	1. **Spanish's 3-form plural** is the only authoring change. Current CLDR `es` cardinal = `{one, many, other}`; `many` fires only on large/compact numbers (e.g. millions), but every `es` ICU plural message must still carry a `many {…}` arm or `intl-messageformat` falls back. Flag it to the reviewer and extend the parity/lint check. (th/id/zh/ja/ko are **single-form** → trivial; da is 2-form like en.)
44	2. **Fonts split the batch.** es/da/id need **no new font** (Latin). th needs one **small** OFL font. **zh-Hans/ja/ko need large OFL CJK fonts** — all OFL-1.1 (bundleable under ED2), all on `@fontsource-variable`, but multi-MB each.
45	3. **CJK + the offline guard collide.** `@fontsource` serves CJK as ~100+ `unicode-range` `woff2` chunks, fetched on demand — efficient *online*, but the SPA's **air-gapped/offline guarantee** (`hygiene.test.ts` "offline / self-contained") means we must ship **all** chunks so any glyph renders with no network → **tens of MB** added with 3 CJK languages.
