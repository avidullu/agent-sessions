### Critical Constraints & Trade-offs

**Performance:** Full-pipeline run is **expensive** (segmentation hits GPU/Gemini + stitching encodes video). Current nightly re-scores cached trajectories (CPU, ~seconds). Full run = **10-60 min per video**. 
- **Option A:** Use 1-2 short synthetic test videos (< 1 min each) to keep nightly under time budget
- **Option B:** Run full-corpus test as a separate on-demand task (not nightly)

**Determinism:** Reel counts must be stable across re-runs. Confirmed for WASB native stream path (2026-06-20 validation), but needs owner confirmation on their machine.

**Baseline bloat:** Current `nightly_baseline.json` ~100 KB. Adding full segment lists per video could balloon to MBs. Recommend storing only the COUNT, not full segment metadata.

**Manifest points to local files:** Golden videos live outside the repo on the owner's machine (not cached). Manifest must have valid file paths or fetched URIs.
