51	### 2.1 Match rule (asymmetric tolerance — forgive the start, expose the end)
52	A predicted window matches a golden rally iff **`|Δstart| ≤ τ_start` AND `|Δend| ≤ τ_end`**.
53	- **`τ_start` generous (~2.0 s)** — absorbs the service-window/annotator start fuzziness (the part that is
54	  *not* a model deficit).
55	- **`τ_end` tighter (~1.5 s, but IAA-calibrated — see §2.4)** — the rally-end IS a sharp physical event
56	  (shuttle down/net/out), so a loose end *is* a real deficit we want the metric to expose, not forgive.
57	
58	> A *symmetric* ±2 s tolerance is tempting (the owner's stated bar) but the preview (§3) shows it is **not**
59	> automatically more lenient than tIoU 0.5 and it blurs exactly the end-deficit we need to see. Asymmetry is
60	> the point: relax the dimension that's intrinsically fuzzy (start), keep honest the one that's a real event (end).
61	
62	### 2.2 Assignment — strict 1:1 (Hungarian), never overlap/greedy
63	Match references to predictions by **global Hungarian assignment** (max total matches under the tolerance
64	gate), one-to-one. This is what makes **over-production cost precision directly**: `P@τ = matched / n_pred`
65	crashes when the detector emits 75 windows for 52 rallies. (tIoU's overlap matching let extras "match
66	something"; the W1 over-segmentation pendulum was barely costed.)

69	1. **`P@τ`, `R@τ`, `F1@τ`** — precision (over-production), recall (did we find the rally within tolerance), F1.
70	2. **Boundary-error distributions** — median **+ IQR** of signed *and* absolute `Δstart`, `Δend` over matched
71	   pairs, **split**. This is the metric that says *"start solved, end open"* and aims R4.
72	3. **Over-seg guard (mandatory):** `split_count` (preds covering one ref — W1 over-seg) and `merge_count`
73	   (refs under one pred — the baseline mega-window). The *original* rule was strict per-video: **a promotion
74	   may not increase either on ANY video.** **REFINED to a NET guard, 2026-06-17 (R1, owner-approved)** — the
75	   strict rule is correct for an *incremental* cue but **mis-fires on a structural mega-window→bounded change**
76	   (splitting a mega-window necessarily lifts `split_count` from ~0, and the raw merge *count* is non-monotonic:
77	   one window hiding 40 rallies is `count=1, rate=1.0`; bounding it into pieces that each glue 2 neighbours is
78	   `count=9, rate=0.5` — FEWER rallies hidden). The net guard scores over-seg on the **normalized rates** as one
79	   weighted cost per video (`w_merge·merge_rate + w_split·split_rate`, merges weighted higher — a merge hides a

36	Snapshot the baseline from current HEAD (after an intended improvement or a corpus change):
37	
38	    python scripts/nightly_regression.py --update-baseline
39	
40	Nightly check (exit 1 on regression; writes ``output/nightly_regression/<date>.md`` + ``.json``):
41	
42	    python scripts/nightly_regression.py
43	
44	Exit codes
45	----------
46	* ``0`` — all tracked configs clean (no regression), corpus matches the baseline.
47	* ``1`` — at least one regression (an aggregate metric dropped beyond tolerance, or a per-video
48	  over-seg guard increased). Takes precedence over a stale baseline.
49	* ``2`` — operational error (manifest/corpus missing, nothing scored).
50	* ``3`` — no baseline to compare against (snapshot one with ``--update-baseline``).
51	* ``4`` — baseline STALE (the corpus set or a config definition changed): a refresh is needed,
52	  but no regression was found on the comparable intersection.

215	def summarize_run(eval_result: Dict[str, Any]) -> Dict[str, Any]:
216	    """Compact, comparable summary of one :func:`rally_seg_eval.evaluate` result.
217	
218	    Keeps only the deterministic quantities we compare — aggregate MEANS (not the bootstrap CI,
219	    which is seeded but irrelevant to the gate) and per-video RAW metric values."""
220	    agg = eval_result.get("aggregate", {}) or {}
221	    aggregate = {
222	        k: (agg[k]["mean"] if isinstance(agg.get(k), dict) else None)
223	        for k in AGG_SNAPSHOT
224	    }
225	    per_video = {
226	        r["name"]: {k: r[k] for k in PV_SNAPSHOT if k in r}
227	        for r in eval_result.get("rows", [])
228	    }
229	    return {
230	        "n": int(agg.get("n", len(eval_result.get("rows", [])))),
231	        "preset": eval_result.get("preset"),
232	        "min_crossings": eval_result.get("min_crossings", 0),
233	        "iou": eval_result.get("iou", DEFAULT_IOU),
234	        "aggregate": aggregate,
235	        "per_video": per_video,
236	    }

239	@dataclass
240	class Finding:
241	    """One comparison outcome line (regression / improvement / stale note)."""
242	
243	    config: str
244	    scope: str  # "aggregate" | "per_video" | "config"
245	    metric: str
246	    kind: str  # "regression" | "improvement" | "stale"
247	    baseline: Optional[float] = None
248	    current: Optional[float] = None
249	    video: Optional[str] = None
250	
251	    @property
252	    def delta(self) -> Optional[float]:
253	        if self.baseline is None or self.current is None:
254	            return None
255	        return self.current - self.baseline
256	
257	    def message(self) -> str:
258	        loc = (
259	            f"{self.config}/{self.video}/{self.metric}"
260	            if self.video
261	            else f"{self.config}/{self.metric}"
262	        )
263	        if self.kind == "stale":
264	            return f"[STALE] {self.config}: {self.metric}"
265	        d = self.delta
266	        ds = f"{d:+.4f}" if d is not None else "—"
267	        b = "—" if self.baseline is None else f"{self.baseline:.4f}"
268	        c = "—" if self.current is None else f"{self.current:.4f}"
269	        tag = "REGRESSION" if self.kind == "regression" else "improvement"
270	        return f"[{tag}] {loc}: {b} → {c} ({ds})"

293	def _preset_comparable(base_preset: Any, cur_preset: Any) -> bool:
294	    """Are the two stored preset dicts the same windowing definition? (name is cosmetic)."""
295	    if not isinstance(base_preset, dict) or not isinstance(cur_preset, dict):
296	        return base_preset == cur_preset
297	    keys = set(base_preset) | set(cur_preset)
298	    return all(base_preset.get(k) == cur_preset.get(k) for k in keys if k != "name")

301	def compare_config(
302	    name: str, base_sum: Dict[str, Any], cur_sum: Dict[str, Any], tols: Tolerances
303	) -> ConfigComparison:
304	    """Compare one config's current summary to its baseline summary.
305	
306	    * If the preset definition or the net-crossings gate changed, the whole config is STALE
307	      (numbers aren't comparable) — flag it, skip gating.
308	    * If the corpus (video set) changed, the aggregate is not comparable (different videos) →
309	      skip the aggregate gate + flag added/removed, but STILL run the per-video gate on the
310	      INTERSECTION (a code regression on a shared video must still trip the wire).
311	    """
312	    cmp = ConfigComparison(config=name)
313	
314	    # 1) Config-definition drift → stale, not gateable.
315	    if not _preset_comparable(
316	        base_sum.get("preset"), cur_sum.get("preset")
317	    ) or base_sum.get("min_crossings") != cur_sum.get("min_crossings"):
318	        cmp.status = "stale"
319	        cmp.aggregate_gated = False
320	        cmp.findings.append(
321	            Finding(config=name, scope="config", metric="preset", kind="stale")
322	        )
323	        return cmp
324	
325	    base_pv = base_sum.get("per_video", {})
326	    cur_pv = cur_sum.get("per_video", {})
327	    base_names, cur_names = set(base_pv), set(cur_pv)
328	    cmp.added_videos = sorted(cur_names - base_names)
329	    cmp.removed_videos = sorted(base_names - cur_names)
330	    corpus_changed = bool(cmp.added_videos or cmp.removed_videos)
331	
332	    # 2) Aggregate gate (only when the corpus matches — means over different sets aren't comparable).
333	    if corpus_changed:
334	        cmp.aggregate_gated = False
335	        cmp.status = "stale"
336	        cmp.findings.append(
337	            Finding(config=name, scope="config", metric="corpus", kind="stale")
338	        )
339	    else:
340	        base_agg = base_sum.get("aggregate", {})
341	        cur_agg = cur_sum.get("aggregate", {})
342	        for m in GATED_HIGHER:
343	            b, c = base_agg.get(m), cur_agg.get(m)
344	            if b is None or c is None:
345	                continue
346	            if c < b - tols.metric_tol:
347	                cmp.findings.append(Finding(name, "aggregate", m, "regression", b, c))
348	            elif c > b + tols.metric_tol:
349	                cmp.findings.append(Finding(name, "aggregate", m, "improvement", b, c))
350	        for m in GATED_LOWER:
351	            b, c = base_agg.get(m), cur_agg.get(m)
352	            if b is None or c is None:
353	                continue
354	            if c > b + tols.rate_tol:
355	                cmp.findings.append(Finding(name, "aggregate", m, "regression", b, c))
356	            elif c < b - tols.rate_tol:
357	                cmp.findings.append(Finding(name, "aggregate", m, "improvement", b, c))
358	
359	    # 3) Per-video over-seg guard on the intersection (always — catches per-video code regressions).
360	    for vid in sorted(base_names & cur_names):
361	        for m in PER_VIDEO_GUARD:
362	            b, c = base_pv[vid].get(m), cur_pv[vid].get(m)
363	            if b is None or c is None:
364	                continue
365	            if c > b + tols.over_seg_tol:
366	                cmp.findings.append(
367	                    Finding(
368	                        name,
369	                        "per_video",
370	                        m,
371	                        "regression",
372	                        float(b),
373	                        float(c),
374	                        video=vid,
375	                    )
376	                )
377	
378	    if cmp.regressions:
379	        cmp.status = "regression"
380	    elif cmp.status != "stale":
381	        cmp.status = "ok"
382	    return cmp

385	@dataclass
386	class NightlyResult:
387	    comparisons: List[ConfigComparison] = field(default_factory=list)
388	    skipped: Dict[str, List[str]] = field(
389	        default_factory=dict
390	    )  # config -> manifest videos not scored
391	
392	    @property
393	    def has_regression(self) -> bool:
394	        return any(c.status == "regression" for c in self.comparisons)
395	
396	    @property
397	    def has_stale(self) -> bool:
398	        return any(c.status == "stale" for c in self.comparisons)
399	
400	    def overall_status(self) -> str:
401	        if self.has_regression:
402	            return "REGRESSION"
403	        if self.has_stale:
404	            return "STALE"
405	        return "PASS"
406	
407	    def exit_code(self) -> int:
408	        if self.has_regression:
409	            return 1
410	        if self.has_stale:
411	            return 4
412	        return 0

415	def compare_all(
416	    baseline: Dict[str, Any],
417	    current: Dict[str, Any],
418	    tols: Tolerances,
419	    skipped: Optional[Dict[str, List[str]]] = None,
420	) -> NightlyResult:
421	    """Compare every tracked config's current summary to the baseline summary."""
422	    res = NightlyResult(skipped=skipped or {})
423	    base_cfgs = baseline.get("configs", {})
424	    cur_cfgs = current.get("configs", {})
425	    for name in cur_cfgs:
426	        if name not in base_cfgs:
427	            cmp = ConfigComparison(config=name, status="stale", aggregate_gated=False)
428	            cmp.findings.append(
429	                Finding(
430	                    config=name,
431	                    scope="config",
432	                    metric="missing_in_baseline",
433	                    kind="stale",
434	                )
435	            )
436	            res.comparisons.append(cmp)
437	            continue
438	        res.comparisons.append(
439	            compare_config(name, base_cfgs[name], cur_cfgs[name], tols)
440	        )
441	    return res

451	def format_report(
452	    baseline: Dict[str, Any],
453	    current: Dict[str, Any],
454	    result: NightlyResult,
455	    tols: Tolerances,
456	    date: str,
457	) -> str:
458	    L: List[str] = []
459	    status = result.overall_status()
460	    badge = {
461	        "PASS": "✅ PASS",
462	        "REGRESSION": "🔴 REGRESSION",
463	        "STALE": "🟡 STALE (baseline refresh needed)",
464	    }[status]
465	    L.append(f"# Nightly rally-quality regression — {date}")
466	    L.append("")
467	    L.append(f"**Status: {badge}**  ·  exit code {result.exit_code()}")
468	    L.append("")
469	    L.append(
470	        f"- HEAD: `{current.get('git_commit', '?')}`  ·  baseline: "
471	        f"`{baseline.get('git_commit', '?')}` (snapshot {baseline.get('generated_at', '?')})"
472	    )
473	    L.append(
474	        f"- Corpus manifest: `{current.get('manifest', '?')}`  ·  IoU={current.get('iou', DEFAULT_IOU)}"
475	    )
476	    L.append(
477	        f"- Tolerances: metric ±{tols.metric_tol}, rate ±{tols.rate_tol}, "
478	        f"per-video over-seg +{tols.over_seg_tol}"
479	    )
480	    L.append("")
481	
482	    # Up-front regression / stale summary.
483	    regs = [f for c in result.comparisons for f in c.regressions]
484	    if regs:
485	        L.append("## 🔴 Regressions")
486	        L.append("")
487	        for f in regs:
488	            L.append(f"- {f.message()}")
489	        L.append("")
490	    if result.has_stale:
491	        L.append("## 🟡 Stale / not comparable")
492	        L.append("")
493	        for c in result.comparisons:
494	            if c.status == "stale":
495	                if c.added_videos:
496	                    L.append(f"- `{c.config}`: corpus added {c.added_videos}")
497	                if c.removed_videos:
498	                    L.append(f"- `{c.config}`: corpus removed {c.removed_videos}")
499	                if not c.added_videos and not c.removed_videos:
500	                    L.append(
501	                        f"- `{c.config}`: config definition changed vs baseline → re-snapshot with --update-baseline"
502	                    )
503	        L.append(
504	            "- Action: `python scripts/nightly_regression.py --update-baseline` (after confirming the change is intended)."
505	        )
506	        L.append("")
507	
508	    # Skipped (no silent caps).
509	    skipped_any = {k: v for k, v in result.skipped.items() if v}
510	    if skipped_any:
511	        L.append(
512	            "## ⚠ Skipped manifest videos (missing trajectory or GT — NOT silently dropped)"
513	        )
514	        L.append("")
515	        for cfg, vids in skipped_any.items():
516	            L.append(f"- `{cfg}`: {vids}")
517	        L.append("")
518	
519	    # Per-config detail.
520	    cur_cfgs = current.get("configs", {})
521	    base_cfgs = baseline.get("configs", {})
522	    for cmp in result.comparisons:
523	        cur = cur_cfgs.get(cmp.config, {})
524	        base = base_cfgs.get(cmp.config, {})
525	        L.append(f"## Config `{cmp.config}` — {cur.get('note', '')}")
526	        L.append("")
527	        L.append(
528	            f"_status: {cmp.status}; n={cur.get('n', '?')} (baseline n={base.get('n', '?')})_"
529	        )
530	        L.append("")
531	        cagg = cur.get("aggregate", {})
532	        bagg = base.get("aggregate", {})
533	        L.append("| metric | baseline | current | Δ | gated |")
534	        L.append("|---|---|---|---|---|")
535	        for m in AGG_SNAPSHOT:
536	            b, c = bagg.get(m), cagg.get(m)
537	            d = (c - b) if (b is not None and c is not None) else None
538	            gated = (
539	                "✓"
540	                if (m in GATED_HIGHER or m in GATED_LOWER) and cmp.aggregate_gated
541	                else ""
542	            )
543	            L.append(f"| {m} | {_fmt(b)} | {_fmt(c)} | {_fmt(d)} | {gated} |")
544	        L.append("")
545	        # Per-video over-seg guard table.
546	        cpv = cur.get("per_video", {})
547	        bpv = base.get("per_video", {})
548	        names = sorted(set(cpv) | set(bpv))
549	        if names:
550	            L.append("| video | tolF1 (b→c) | split (b→c) | merge (b→c) |")
551	            L.append("|---|---|---|---|")
552	            for v in names:
553	                cb, cc = bpv.get(v, {}), cpv.get(v, {})
554	                tf = f"{_fmt(cb.get('tol_f1'))}→{_fmt(cc.get('tol_f1'))}"
555	                sp = f"{cb.get('split_count', '—')}→{cc.get('split_count', '—')}"
556	                mg = f"{cb.get('merge_count', '—')}→{cc.get('merge_count', '—')}"
557	                flag = (
558	                    " 🔴"
559	                    if any(
560	                        f.video == v and f.kind == "regression" for f in cmp.findings
561	                    )
562	                    else ""
563	                )
564	                L.append(f"| {v}{flag} | {tf} | {sp} | {mg} |")
565	            L.append("")
566	        imps = cmp.improvements
567	        if imps:
568	            L.append(
569	                "_Improvements over baseline (consider `--update-baseline` to ratchet the floor up):_"
570	            )
571	            for f in imps:
572	                L.append(f"- {f.message()}")
573	            L.append("")
574	
575	    L.append("---")
576	    L.append(
577	        "_Tripwire only — re-scores CACHED trajectories (no GPU/Gemini/WASB). Does not change "
578	        "the promotion gate. See docs/R2_EVAL_METRIC_DESIGN.md + memory/eval-dual-set-regression._"
579	    )
580	    return "\n".join(L)
