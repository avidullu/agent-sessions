## Key Components

**Trident-head (Boundary Detection):**
The Trident-head estimates the boundary offset based on a relative distribution predicted by three branches: Start Boundary, End Boundary and Center Offset. **SGP (Scalable-Granularity Perception) Layer:**
Pyramid features are built with Scalable-Granularity Perception (SGP) layer, and corresponding features in each level are fed into a shared-weight detection head. The SGP layer mitigates the rank loss problem of self-attention that takes place in the video features and aggregates information across different temporal granularities.
