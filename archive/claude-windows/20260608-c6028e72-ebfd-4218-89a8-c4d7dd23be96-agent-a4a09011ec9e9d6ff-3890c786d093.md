## Overview
TriDet is code for the paper "Temporal Action Detection with Relative Boundary Modeling" which has been accepted for CVPR2023. It presents a one-stage framework for temporal action detection.

## GitHub Repository
The code is built upon the codebase from ActionFormer and Detectron2. The official repository is located at https://github.com/dingfengshi/TriDet.
