## Core Approaches

Nester is a method for injecting neural networks into constrained structured predictors, where the neural network computes an initial raw prediction that doesn't necessarily satisfy constraints, and the structured predictor then builds a structure using a constraint solver that assembles and corrects the raw predictions in accordance with hard and soft constraints.
