## AGPL License Requirements

AGPL is stricter than GPL: Even cloud/SaaS deployments must be open-source modifications. This means there is no inherent SaaS loophole in the AGPL-3.0 license itself—the license specifically extends its requirements to cloud and SaaS deployments.

## Ultralytics' Licensing Approach

Rather than exploiting a loophole, Ultralytics offers a dual-licensing model:

An Enterprise License provides organizations with the ability to modify Ultralytics YOLO source code and embed Ultralytics YOLO code and models in commercial products without needing to follow the constraints of the AGPL-3.0 License, namely the requirement to open-source modified works or larger works containing Ultralytics YOLO code and models. ## Criticism of Ultralytics' License Framing

One GitHub issue raised concerns about how Ultralytics presents the AGPL license. The GNU AGPLv3 License allows Commercial Use, if all other License Conditions are met. Also, the GNU AGPLv3 License allows Private Use. If a user uses licensed material privately without distribution, the primary obligations of the GNU AGPLv3 License are not triggered (so no sharing externally/open sourcing is obligated).

In summary, there isn't a documented "loophole"—rather, Ultralytics offers an Enterprise License option for organizations wanting to keep their code closed source, while the AGPL-3.0 license itself does extend to SaaS deployments without exceptions.
