## MPL-2.0 Overview

MPL 2.0 is often termed a "weak copyleft" license, falling somewhere in the middle of the license spectrum. The MPL's "file-level" copyleft is designed to encourage contributors to share modifications they make to your code, while still allowing them to combine your code with code under other licenses (open or proprietary) with minimal restrictions.

## File-Level Copyleft Mechanism

The MPL copyleft applies to any files containing MPLed code, whereas LGPL applies to any library based on LGPLed code, and GPL applies to all software based on GPLed code. This means only modified MPL files must remain open source, and new files can use any license.

## Comparison with Other Licenses

**MPL-2.0 vs. MIT/BSD (Permissive):**
The MPL is a compromise between the MIT or BSD licenses, which permit all derived works to be relicensed as proprietary, and the GPL, which requires the derived work as a whole to be licensed under the GPL.

**MPL-2.0 vs. GPL/LGPL (Strong Copyleft):**
MPL only requires modifications to MPL licensed code to be released, whereas GPL affects other code linked to GPL licensed files. Weak copyleft licenses like MPL-2.0 fill a niche between strong copyleft licenses, such as the GPLs, and permissive ones like MIT or Apache License 2.0.

**Compatibility:**
The MPL 2.0 is compatible with GPL v2 or later, LGPL 2.1 or later, and/or AGPL 3.0 or later.
