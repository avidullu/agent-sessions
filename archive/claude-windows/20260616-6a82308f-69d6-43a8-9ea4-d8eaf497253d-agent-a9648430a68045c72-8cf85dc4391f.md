# Shot Refinement Method Summary

## Hit Detection Approach

The method combines two detection streams:

1. **Trajectory-Based Detection (HD-T)**: Uses TrackNet's "Peak Identification Method" and "Direction Identification Method" to detect sudden changes in shuttlecock direction—specifically identifying hits at trajectory turning points where flight direction reverses.

2. **Action-Based Detection (HD-A)**: Applies YOLOv7 to detect player swing motions, generating confidence scores for hitting actions per frame.

## Shot Refinement Algorithm (SRA)

The algorithm merges both detections through five cases:
- **Case 1**: Single trajectory detection within a swing segment = confirmed hit
- **Case 2**: Trajectory detection in non-swing segments = false positive (removed)
- **Case 3**: Multiple trajectory detections in one swing = retain closest to highest-confidence frame
- **Case 4**: No trajectory detection but swing detected = use highest-confidence frame as hit moment
- **Case 5**: No detections in non-swing segments = true negative

- **Enhancing Badminton Game Analysis (Sensors 2024)** is the strongest blueprint: it detects hits at trajectory turning points (TrackNet Peak/Direction methods) and fuses them with a YOLOv7 swing classifier via a 5-case Shot Refinement Algorithm that explicitly removes trajectory-only false positives in non-swing segments (knock-ups). This raises F1 from 72.3% (trajectory alone) to 90.5%. This is the cue that separates "rally" from "shuttle merely moving."
- **Service and End of Rally Detection / Ready-to-Serve (See et al. 2024)** treats serve-onset and rally-end as explicit boundary states — the missing "split on serve" signal.
- **Table Tennis Stroke Detection (2023)** proves 1-D trajectory alone can yield serve and missed-stroke (dead-time) boundaries via a mathematical boundary-extraction step.
- **MonoTrack** uses court geometry/shot placement (not just velocity) to segment rallies and shots.
- **Hit-frame Detection (2023)** and **Real-Time Broadcast Analysis (2023)** show the cascade pattern: a coarse in-play/dead-time gate before fine boundary detection, and the rally-vs-non-rally class framing.

Two caveats flagged in the results: several sources are broadcast (BWF) video rather than the project's amateur non-broadcast setting, and the Springer pages are auth-gated (citable as named prior art, abstract-level only).
