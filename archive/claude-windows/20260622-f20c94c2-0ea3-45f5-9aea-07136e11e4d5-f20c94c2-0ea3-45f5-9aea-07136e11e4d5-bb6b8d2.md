``run.log`` — the very thing the owner eyeballs during manual QA.

The suppression is config-gated (``logging.verbose_http``) so request-flow debugging can

import logging

#: default so only genuine warnings/errors from them reach run.log.

    "httpx",
    "httpcore",
    "urllib3",
    "google_genai",   # google-genai SDK (underscore form)
    "google.genai",   # dotted form, depending on SDK version
    "google.auth",
    "grpc",
)

_DATE_FORMAT = "%H:%M:%S"
