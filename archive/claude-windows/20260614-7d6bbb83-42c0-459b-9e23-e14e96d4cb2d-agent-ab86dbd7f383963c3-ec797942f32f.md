## Stacked Generalization Overview

Stacking, also known as Stacked Generalization, is an ensemble technique that combines multiple classifications or regression models via a meta-classifier or a meta-regressor.

## How It Works

The base-level models are trained on a complete training set, then the meta-model is trained on the features that are outputs of the base-level model. More specifically, the predictions (or probabilities) from the base models form the new feature set for the meta-model.

## Key Components

Stacking allows any machine learning model to be used to learn how to best combine the predictions from contributing members. The model that combines the predictions is referred to as the meta-model, whereas the ensemble members are referred to as base-models.

The base-level often consists of different learning algorithms and therefore stacking ensembles are often heterogeneous.

## Meta-Learner Function

In a stacking ensemble, a strong learner (also called meta learner, because it learns from the learnings of other learners) chosen as the final classifier, makes and learns to make the final prediction. This layered approach allows the meta-model to learn the best way to weigh and combine the individual strengths and weaknesses of the base models.

## Mixture of Experts (MoE)

Mixture of experts (ME) is one of the most popular ensemble learning methods introduced by Jacobs et al. in 1991. The modular architecture of ME consists of some experts and a gating network which learns the input space decomposition and also aggregates the outputs of experts dynamically according to the expertise of each expert in created subspaces.

## Gating Networks

The Gating Network is a model that determines which expert(s) should contribute to a given prediction. The output of each expert is weighted by the gating network using softmax normalization. Combining the expert outputs may include weighting the expert output generated by each of the selected expert neural networks by the weight for the selected expert neural network to generate a weighted expert output, and summing the weighted expert outputs to generate the MoE output.

## Combining Multiple Experts

To combine the logits from multiple experts, one can dynamically fuse the experts' logits using a gating mechanism that learns to weigh them. Simple fixed fusion rules such as the product and sum are employed as the aggregating operator.

## Calibration in Expert Systems

The Mixture of Calibrated Experts (MoCaE) framework introduces a principled approach to aggregating predictions from multiple detectors, addressing miscalibrated confidence outputs by calibrating each expert's output based on empirical performance.

## Modality Competition and Joint Training Challenges

The best uni-modal network has been observed to outperform the jointly trained multi-modal network, which is counter-intuitive since multiple signals generally bring more information. This phenomenon is explained by a theoretical and empirical framework:

For multi-modal late-fusion networks with ReLU activation trained jointly by gradient descent, different modalities compete with each other, causing encoder networks to learn only a subset of modalities—a phenomenon referred to as modality competition. The losing modalities, which fail to be discovered, are the origins of joint training's sub-optimality.

## Greedy Modality Utilization

Multimodal DNN learning exhibits inherent greediness, where models unevenly utilize each modality, limiting the utilization of all available information and leading to poor generalization performance.

## Convergence Dynamics

Empirical evidence shows convergence issues during joint training: The performance of each modality during joint training consistently lags behind that achieved through independent training. ## Overview

Stacked generalization (or stacking) by Wolpert (1992) is a different way of combining multiple models, that introduces the concept of a meta learner.

## How It Works

Stacking is a general framework that comprises at least two levels. The first level involves training the individual forecasting models using the original data, while the second and any subsequent levels utilize an additional "meta-model", using the prior level forecasts as inputs to form a set of forecasts.

More specifically, the first step is to collect the output of each model into a new set of data. ## Key Concepts

**Leave-One-Subject-Out (LOSO) Cross-Validation:**
LOSO CV is a cross-validation strategy for assessing model generalization in datasets with grouped or repeated-measures structure. It evaluates model performance on grouped data by iteratively holding out one subject per fold, ensuring independent and robust error estimates.

## Preventing Data Leakage

The fundamental problem with grouped data is preventing leakage. Leave-one-subject-out or grouped cross-validation avoids record-level leakage and yields more honest estimates of generalization. Windows are not independent because many windows belong to the same subject, so group-wise splitting by subject is enforced to prevent train-test leakage.

## Proper Implementation

All subject-level artifact removal, normalization, and transformation should be performed before folding, preventing leakage of subject-specific information.
