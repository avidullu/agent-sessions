## The Core GPL vs AGPL Difference

The AGPL is identical to GPL3 except for clause 13, which states that making software available over a network triggers the copyleft. This addresses a significant loophole in the standard GPL.

## The "Mere Interaction" Definition

Both GPL and AGPL define what "conveying" means: "To 'convey' a work means any kind of propagation that enables other parties to make or receive copies. Mere interaction with a user through a computer network, with no transfer of a copy, is not conveying."

## The SaaS Loophole

This definition creates what's often called the "SaaS loophole" in regular GPL licenses. Building a web app on top of GPL code and making that web app available over the internet is not conveying the work. This means companies can run modified GPL software as a service without sharing their modifications if they don't distribute the code itself.

## AGPL's Section 13 Solution

The AGPL's clause 13 states that if you modify the Program, your modified version must prominently offer all users interacting with it remotely through a computer network an opportunity to receive the Corresponding Source of your version by providing access to the Corresponding Source from a network server at no charge.

However, AGPL has a second condition that the program has to be 'modified'. SaaS use of an unmodified AGPL program – most SaaS use – therefore does not trigger copyleft.
