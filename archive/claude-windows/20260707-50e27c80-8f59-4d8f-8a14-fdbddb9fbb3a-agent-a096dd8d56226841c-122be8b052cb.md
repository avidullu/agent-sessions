+    """``F.grid_sample`` sampling grid replicating ``cv2.warpAffine(img, trans,
+    (inp_w, inp_h), INTER_LINEAR)`` — THE #506 lesson lives here.

+    The GPU resize MUST be WASB's affine warp (center/scale geometry + cv2's
+    integer-coordinates-are-pixel-centers convention), NOT a plain resize:
+    ``F.interpolate``'s half-pixel mapping shifts every sample by a constant
+    sub-pixel offset, which tips the sigmoid past ``score_threshold`` on marginal
+    frames and silently over-detects — F1 0.58 → 0.07 on the hard clip GX010128,
+    while the easy clip masked it at 98% agreement. Locked by a cv2-parity unit test.
+
+    ``trans_inv`` is WASB's INVERSE affine (``get_affine_transform(..., inv=1)``),
+    mapping output px → source px; each source position is normalized to [-1, 1]
+    via ``gx = (2*x + 1)/W - 1`` (cv2's half-pixel convention). Pure torch+numpy —
+    no WASB imports — so the parity test runs on any CPU box.
+
+    Returns a ``[1, inp_h, inp_w, 2]`` float32 grid for ``F.grid_sample(...,
+    mode='bilinear', align_corners=False, padding_mode='border')``.
+    """
+    import numpy as np
+    import torch
+
+    ys, xs = torch.meshgrid(
+        torch.arange(inp_h, dtype=torch.float32),
+        torch.arange(inp_w, dtype=torch.float32),
+        indexing="ij",
+    )
+    out_coords = torch.stack([xs, ys, torch.ones_like(xs)], dim=-1)  # [H,W,3] output px
