# Technical Summary: CausalTAD for Temporal Action Detection

## (1) Core Method & Temporal Causality Modeling

**Method Name:** CausalTAD combines causal attention and causal Mamba in a hybrid block.

The core innovation addresses a fundamental assumption in prior work. As stated: *"these modules typically treat past and future information equally, overlooking the crucial fact that changes in action boundaries are essentially causal events."*

**Causal Attention Implementation:**
The method restricts attention via a causal mask. For backward attention (past-only context): *"M_{ij} = 0 if i ≤ j, else -∞"* This ensures *"each position in the sequence can only attend to its past and present positions, effectively modeling temporal causality."*

**Causal Mamba Block:**
Follows decomposed bidirectional design from VideoMambaSuite, with *"input projectors learned separately in each direction, while the parameters in the forward and backward MHSA...are shared."*

## (2) Detection Head & Boundary Handling

The paper builds on **ActionFormer**, described as *"a simple yet effective one-stage anchor-free method."* It employs:
- Regression loss for boundary prediction (hyperparameter: regression loss weight)
- Channel dropout (hyperparameter: probability of input channel dropout)
- Post-processing with Soft-NMS for redundant proposal elimination

No explicit over-segmentation handling discussed beyond standard NMS with configurable sigma threshold.
