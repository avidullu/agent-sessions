## Methods and Approach

The work employs a multi-stage pipeline for stroke analysis:

**Ball Tracking:** Two object detection approaches were implemented and benchmarked—"YOLOv4, a traditional object detection model, and TrackNetv2, a temporal heatmap based model."

**Stroke Segmentation:** The authors developed a mathematical method to extract temporal boundaries. They explain that "a mathematical approach developed to extract temporal boundaries of strokes using the ball trajectory data yielded a total of 2023 valid strokes."

**Stroke Classification:** The system uses "a temporal convolutional network developed [that] performed stroke recognition on completely unseen data." Additionally, the authors note that "several machine learning and deep learning based model architectures have been trained for stroke recognition."

## Key Results

- **Accuracy on unseen data:** 87.155%
- **Dataset size:** 2,023 valid strokes from four professional players across six stroke classes
- **Additional capabilities:** The system successfully "detecting services and missed strokes"

## Dataset and Novel Contribution

The dataset was captured using "a single camera setup positioned in the umpire's view." The work's innovation lies in demonstrating that "meaningful inferences such as stroke detection and recognition can be drawn using minimal input information"—specifically ball trajectory alone, rather than analyzing player body movements.
