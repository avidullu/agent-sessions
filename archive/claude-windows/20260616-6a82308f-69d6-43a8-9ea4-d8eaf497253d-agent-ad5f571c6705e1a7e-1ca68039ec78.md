## 3. Core Method

B-ACT operates through a two-stage hierarchical loop:

**Stage 1 - Video Selection:** The framework ranks unlabeled videos using predictive uncertainty via Monte Carlo Dropout. "Videos with high average uncertainty U(j) contain more frames where the model is uncertain, suggesting higher potential gain from annotation."

**Stage 2 - Boundary-Centric Clip Selection:** Within selected videos, the method:
- Detects candidate action boundaries where predicted labels change
- Scores boundaries using a composite metric (Eq. 13) combining:
  - **Local uncertainty:** Average predictive entropy within a temporal window
  - **Confidence gap:** Margin between top-1 and top-2 class probabilities (inverted)
  - **Temporal gradient:** L2 distance between consecutive predicted distributions

**Annotation Protocol:** "Only the center-frame label ybk(i)(i) for each clip" is annotated, while surrounding unlabeled frames provide temporal context during training. Per-video cost = K labeled frames (typically K=5).
