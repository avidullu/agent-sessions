## Installer WebView2 Options

Tauri provides four primary approaches for handling WebView2 installation:

1. **Downloaded Bootstrapper** (default): Fetches and executes the bootstrapper during installation. Minimal installer overhead but requires internet connectivity. Not ideal for Windows 7 via `.msi` files.

2. **Embedded Bootstrapper**: Bundles the bootstrapper within the installer, adding approximately 1.8MB. Requires internet but offers better Windows 7 compatibility.

3. **Offline Installer**: Embeds the complete WebView2 installer, increasing package size by roughly 127MB. Enables offline installation scenarios.

4. **Fixed Version**: Distributes a specific WebView2 runtime version, expanding the installer by approximately 180MB. Grants direct control over runtime patching and distribution.

Each option balances installer size, connectivity requirements, and deployment flexibility based on your application's target environment.
